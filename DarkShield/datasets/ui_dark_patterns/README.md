# UI Dark-Pattern Dataset Integration Point

This folder is reserved for a future UI or screenshot dark-pattern dataset such as ContextRico-DP.

Visual datasets can support signals that cannot be determined from click sequences alone, including:

- deceptive button hierarchy
- visual misdirection
- disguised advertisements
- confusing choice presentation
- visual prominence manipulation

Image analysis is not implemented in the current prototype. This folder documents the planned integration point only.
